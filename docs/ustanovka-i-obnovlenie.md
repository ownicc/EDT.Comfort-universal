# Установка и обновление

## Через интернет

1. Открыть **Справка → Установить новое ПО… → Добавить**.
2. Указать адрес сайта нашего форка:

   `https://ownicc.github.io/EDT.Comfort-universal/`

3. Выбрать **EDT Comfort → Далее → Готово**, затем перезапустить EDT.

Сайт содержит последнюю успешную сборку `master` нашего репозитория.
После каждого успешного запуска **Build p2 archive** он обновляется автоматически.
Справка: [на нашем сайте](https://ownicc.github.io/EDT.Comfort-universal/help/).

## Обновление установленного плагина

Добавьте наш адрес в список сайтов обновления EDT один раз, затем используйте
**Справка → Проверить обновления**. Установленный из ZIP Comfort также можно обновить
через наш сайт; предварительное удаление не требуется.

Если сайт автора уже добавлен, отключите его в списке доступного ПО,
чтобы выбирать сборки нашего форка. Проверка обновлений внутри новой сборки
Комфорта тоже использует наш сайт.

Если новая версия не видна, обновите список доступного ПО для нашего сайта
в **Справка → Установить новое ПО… → Управление…**.

## Установка из архива

1. Скачать [tormozit.comfort.zip](https://ownicc.github.io/EDT.Comfort-universal/tormozit.comfort.zip).
2. Открыть **Справка → Установить новое ПО… → Добавить → Архив…** и выбрать ZIP.
3. Выбрать **EDT Comfort → Далее → Готово**, затем перезапустить EDT.

[Контрольная сумма SHA-256](https://ownicc.github.io/EDT.Comfort-universal/SHA256SUMS) и
[сведения о сборке](https://ownicc.github.io/EDT.Comfort-universal/build-info.json) опубликованы рядом с архивом.
Предыдущие ZIP доступны в artifacts соответствующих запусков GitHub Actions
в течение срока хранения; сайт содержит только текущую сборку.

Плагин не требует Eclipse JDT при установке. Для [орфографии](orfografiya.md)
нужен JDT UI, который можно установить через параметры Комфорта.
